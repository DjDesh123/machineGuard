### machineGuard - ESP32 Equipment Condition Monitor


## Overview
machineGuard is an ESP32-based equipment condition monitoring system that was developed to explore sensor integration, simple embedded control logic and hardware to software interactions. 

The project uses A DHT11 temperature sensor and a HC-SRO4 ultrasonic sensor to monitor the operating conditions and includes logic to support an automated cooling response when the temperature reaches a certain value. The use of an LED is to show faults visually.
